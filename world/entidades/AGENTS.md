# Registro de entidades

Esta pasta não contém entidades narrativas iniciais. Este arquivo é uma instrução administrativa.

Crie entidades apenas quando solicitado pelo autor. Prefira um arquivo por entidade com ID estável, título, tipo, status, visibilidade e IDs dos pilares relevantes. Não preencha campos narrativos desconhecidos com invenções.

Consulte os pilares existentes e entidades relacionadas antes de propor novos fatos. Cite as fontes por caminho. Registre relações com vínculos Markdown; mantenha propostas e dúvidas explícitas.
