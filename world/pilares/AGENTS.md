# Registro de pilares

Esta pasta não contém pilares aprovados inicialmente. Este arquivo é uma instrução administrativa, não um pilar.

Um pilar só pode nascer de conteúdo fornecido ou aprovado pelo autor. Use ID estável, `type: pilar`, status explícito, escopo, exceções conhecidas e fontes da decisão. Uma proposta de pilar continua `status: proposta` até aprovação.

Antes de qualquer revisão, apresente a regra atual, a alteração proposta, os documentos afetados e as consequências. Não resolva contradições reescrevendo silenciosamente a premissa original.
