# Comece aqui — teste do site

> EXEMPLOS TÉCNICOS — nenhum documento desta pasta faz parte do cânone.

Estas pastas ficam dentro do acervo configurado do site, na branch codex/worldbuilding-conteudo. Os arquivos testam a interface; não inventam fatos do mundo.

## Explorar as pastas

- [Exemplo técnico de pilar](pilares/pilar-teste.md)
- [Exemplo técnico de personagem](personagens/personagem-teste.md)
- [Exemplo técnico de local](locais/local-teste.md)

- [Exemplo técnico de evento](eventos/evento-teste.md)

## Roteiro

1. Busque por teste e abra um dos documentos.
2. Filtre por personagem, local ou pilar.
3. Abra os vínculos e confira Referenciado por e a área Conexões.
4. Abra o rascunho de notas na aba Markdown e altere uma frase.
5. Salve, atualize o acervo e confira a alteração no GitHub.

O Git registra arquivos, não pastas vazias. Cada pasta tem um documento para aparecer no navegador.

O site precisa das credenciais privadas configuradas na Vercel para ler e salvar. Criar estas pastas não substitui essa configuração.
